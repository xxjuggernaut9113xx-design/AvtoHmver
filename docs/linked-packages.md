# Same-PC linked .chpack staging

On the native Host, open Organization and choose **Stage linked .chpack**. This stages all downloaded images and videos in the active library. Virtual clips require portable rendering and are excluded from this staging selection.

The Host creates a managed directory beneath `LIBRARY/.avtohmver-linked-packages/`, hard-links each source into its `media` directory, and builds an ordinary portable `.chpack` ZIP with the existing `0.02a` manifest and rating-to-speed tags. Staging links do not duplicate original media bytes. The ZIP itself necessarily stores media bytes; ZIP links are not substituted for portable media. Sources and staging must share a filesystem volume; cross-volume linking reports an error rather than silently copying originals. No administrator privilege or Windows symlink privilege is required for ordinary file hard links.

The Host validates original paths, file identities, sizes, and modification times before and after archive creation. While the Host is running it checks durable staging records every two seconds, with maintenance admission controlling access. If a source moves, disappears, is replaced, or changes, the Host removes that generated staging directory and its managed `.chpack`. It never deletes the original source or a moved source. Restarting the Host resumes validation of existing managed packages. During maintenance or while the Host is stopped, invalidation waits until validation resumes.

The generated path appears in the native status message. The staging row shows progress and has **Cancel staging**. Cancellation interrupts archive reads in bounded chunks and removes partial staging. A copy exported elsewhere is an independent portable package and will not self-destruct; AvtoHmver only removes packages inside its own managed staging directory. Portable export retains its independent behavior and compatibility identifiers. Unsafe filename characters in tags, including the position namespace colon, become hyphens in package filenames; valid existing tag filenames keep their established alphabetical ordering.

Automated checks cover manifest/media round trips, source moves, changes and replacements, preservation of originals and independent portable copies, missing inputs, cancellation before and during staging, and Host-only admission. Browser staging controls and external Cock Hero importer acceptance remain outstanding. These limits must not be treated as complete package-workflow parity.
