Stale-cue prevention: the image channel carries a slot id with per-slot request counters plus a wall-active guard (extracted as `wall_image_is_fresh`, unit-tested), so late decodes from a stopped mode are dropped; only one video decodes at a time through the shared player, and wall image decodes are bounded by the sync channel. Slideshow looping now restarts a fresh pass over the library when the catalog is exhausted (`slideshow_should_loop`, unit-tested) instead of stalling on 'out of images'. Cock Hero playlist fetches carry a request generation through Work/Update; stale results from a preempted or restarted session are dropped (`ch_playlist_is_stale`, unit-tested). Mode preemption (slideshow/wall/Cock Hero starts and manual queue playback) now finishes an active Cock Hero session through `cockhero_finish`, so session logging fires when `ch_log_sessions` is on and empty sessions are never logged (`ch_session_log_payload`, unit-tested); finishing also invalidates in-flight playlist fetches. Clip-job `clip_job_id` preference mutations now queue the PreferenceSaver so resume survives restarts. Pace-phase boundaries, slideshow setting clamps, mode preemption, playlist item conversion, local playlist/log round-trip, and Viewer denial have automated tests (desktop 42 + curator lib 3 new).
