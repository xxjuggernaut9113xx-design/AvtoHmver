# P-01 — Renderer

Recorded: 2026-09-29. Migrated from the native workflow inventory; historical observations retain their original dates where stated.

bundle libmpv, Slint OpenGL texture plus software fallback, efficient stills and safe teardown. H/V permitted stream only. `desktop::mpv_embed` loads install-relative `libmpv-2.dll`/`libmpv.so.2` at runtime and `desktop::player` owns each handle and its software render context in one worker. Bounded command/status/frame channels prevent decoding from stalling Slint; newest opaque RGB0 frames cross to the Slint thread as an image, and Drop joins the worker before destroying libmpv. Host hands the worker a managed-library path; Viewer uses only `Client::playback_source`, which rejects a role without negotiated playback permission and returns its pinned stream URL. Automated result: resolution, unavailable-runtime, control clamping and locked-workspace tests pass; the ignored environment-gated renderer smoke verified the pinned libmpv SHA-256, decoded a generated disposable 64×64 MP4, delivered an opaque 960×540 frame to the Slint boundary, and exited cleanly. OpenGL rendering, Windows/Linux interactive scaling, Viewer remote playback, and fresh installed-package playback remain required before closing this item.
