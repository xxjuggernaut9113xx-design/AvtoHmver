# C-03 — Installers

Recorded: 2026-09-29. Migrated from the native workflow inventory; historical observations retain their original dates where stated.

collision-free Windows NSIS/MSI and Linux Debian/AppImage with identity/scope/upgrade/uninstall-data guarantees. Windows: `curator-host.nsi` + `curator-viewer.nsi` (current-user and all-users variants, Add/Remove Programs registration with DisplayVersion, Start Menu shortcuts, uninstall removes app files/registry but never user data) plus `build-desktop-installers.ps1`; install dirs avoid the data directory. The builder now refuses a missing verified tools directory, Host stages the full media runtime, and Viewer stages the libmpv DLL set used for remote playback. Linux: `build-host-deb.sh` / `build-viewer-deb.sh` produce .debs (.desktop entry, icon, `Depends: libmpv2`, Host recommends mpv/ffmpeg) plus portable tarballs.

2026-09-29 CI change: the release workflow builds Host/Viewer NSIS packages from verified tools, then silently installs, reinstalls, and uninstalls current-user variants while asserting a user-data sentinel survives. The Linux job builds and inspects the existing Debian and portable archives. The updated workflow has not run on GitHub yet; local NSIS is unavailable. MSI and AppImage are not produced by the current scripts.
