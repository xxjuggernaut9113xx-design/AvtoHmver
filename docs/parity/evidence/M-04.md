# M-04 — Import/export

2026-10-26: Organization now exposes source-list import/export, portable
package export, and local-owner linked staging. These actions remain reachable
after the Explorer shell hides legacy sidebar controls. A regression test
invokes each transfer action and verifies its existing handler; remote browser
hosts do not receive the linked action. In an isolated Windows Server browser,
Organization → Stage linked .chpack → Stage library showed progress followed
by the completed local archive path. Live archive/source-move acceptance and
portable-copy preservation are recorded in V-02. External game import remains
unverified.

2026-10-01 portable export follow-up retains the temporary archive for the
response lifetime, holds maintenance admission while reading originals, and
cancels bounded reads on shutdown. It excludes unavailable and virtual media
that has not been rendered. Physical clips are typed as video. Package source
paths must resolve to files inside the library. Export writes accurate
image_count, video_count and total_media alongside the existing 0.02a media
entries, matching a read-only inspection of an existing CockHero V0.04 pack.
Format inspection and byte round trips do not constitute manual game import
acceptance.

Recorded: 2026-09-29. Migrated from the native workflow inventory; historical observations retain their original dates where stated.

source-list, metadata and package workflows with native dialogs, validation/conflicts/progress/cancel. H full; V explicit remote exports only. Host Manage → Organization can save a source-list JSON file through a native save dialog and atomic file replacement, and import a validated JSON source list through a native file picker. The typed export/import operations share Server `GET /api/export` and `POST /api/import` payloads; source creation is a shared service that reports duplicates. Viewer direct import/export is denied. Direct/HTTP source and duplicate parity, parser rejection, Viewer, shutdown and maintenance admission have automated tests. Windows and Linux manual results are unavailable for these new native entry points.
2026-10-01 linked staging: the native Host has an asynchronous **Stage linked .chpack** action, an indeterminate progress indicator, and out-of-band cancellation. Managed hard-link staging produces the existing portable ZIP/manifest format; original path/identity/size/mtime changes remove only its generated staging container and package. Original and moved files remain untouched, and independent portable copies remain independent. The Host resumes durable validation after restart. Tests cover round trips, source moves/changes, originals, portable copies, failed staging, cancellation during bounded archive reads, Host-only admission, and shutdown. See [workflow and exact limits](../../linked-packages.md). Browser staging controls and external importer/manual acceptance remain incomplete.
