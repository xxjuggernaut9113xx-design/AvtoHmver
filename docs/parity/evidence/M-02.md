# M-02 — Organization/sources

Recorded: 2026-09-29. Migrated from the native workflow inventory; historical observations retain their original dates where stated.

nested group CRUD, source edit/inspect/resync/pause/resume/remove/log and clear remove-vs-files distinction. H full; V restricted. Organization prompts for an explicit phrase before removing a source while keeping media or deleting its library folder and archive; the pending source ID is captured before list refreshes and Cancel clears it. Source deletion uses `services::sources::delete` from Host and the unchanged Server `DELETE /api/sources/{id}?delete_files=` adapter, with Viewer permission, maintenance and shutdown admission. Inspect opens an inline editor for name, download inclusion, and retention; Host uses `services::sources::patch` and Server retains `PATCH /api/sources/{id}` fields and validation. The Organization view also creates nested groups, moves groups to a parent or top level, and assigns/ungroups sources using captured IDs; backend cycle checks reject moving a group into its descendant. Source placement uses `services::sources::set_group` directly on Host and the existing Server adapter, with disposable-library direct/HTTP payload parity, Viewer/shutdown, retention and keep/delete-files tests. Source pause/resume and detail/log entry points exist.
