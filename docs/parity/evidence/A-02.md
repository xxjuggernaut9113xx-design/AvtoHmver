# A-02 — Operation control

Recorded: 2026-09-29. Migrated from the native workflow inventory; historical observations retain their original dates where stated.

Separate interaction, jobs, thumbnails and playback; use bounded queues, cancellation, deduplication, progress and actionable errors. Native Host/Viewer use bounded regular (128), control (16), image (1), and preference-save (1) work queues; preference snapshots coalesce to the newest value. A full regular queue reports rejected actions and stale page/preview results cannot replace the current view. Closing the window signals every worker, cancels pending asynchronous image/control/general work, and stops queued work from draining; the general worker checks for shutdown every 100 ms when idle. Unit tests cover control admission, preference coalescing, and in-flight cancellation.
