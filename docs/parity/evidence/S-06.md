2026-10-28 adapter correction: nonfinite upstream confidence values are
discarded before they can become P-HAR evidence. The worker protocol test
covers infinity, NaN, and a valid 0.72 score; Rust continues to require two
adjacent finite scores of at least 0.70 for an automatic position tag.

2026-10-26: native Local Admin exposes backend selection and next-launch
disable, and its navigation entry is reachable alongside Automation. Native
and HTTP controls share a typed classifier service with owner, shutdown and
maintenance admission. Setup threads retain their worker lease and an OS file
lock; GPU probes are bounded and hidden on Windows. A stale in-progress state
can be resumed when its prior process no longer owns the setup lock. Missing
publisher checksums and unavailable verified native runtimes remain explicit
blocked reasons; this change does not claim successful model installation or
classification accuracy on real media.

2026-10-01 implementation: P-HAR adds `position:<label>` tags for doggy,
the-snake, anal, missionary, cowgirl, scoop-up, and 69 when two consecutive,
ordered, adjacent windows detect the same label at confidence >= 0.70.
Non-finite or invalid time windows do not qualify. Tags have automatic
provenance. Human additions promote automatic provenance, while durable tag
removal records suppress reattachment after rescans and global tag deletion.
Classifier evidence and tags commit together. Regression test:
`position_confirmation_and_rescans_preserve_human_overrides`. This fixture test
does not validate classification accuracy on real media or complete remaining
classifier-management native UI parity.
