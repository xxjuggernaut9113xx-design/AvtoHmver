# C-02 — Bundles

Recorded: 2026-09-29. Migrated from the native workflow inventory; historical observations retain their original dates where stated.

libmpv for both editions; ffmpeg/ffprobe/isolated gallery-dl for H; install-relative resolution/overrides, pinned checksums/notices and packaging failure on missing tools. Install-relative resolution is done: `config::resolve_tool_bin` checks `<exe-dir>/tools/<tool>` first, then `CURATOR_<ENV>` overrides, then config.json, then PATH (unit-tested); the renderer independently resolves install-relative libmpv before a permitted override. `packaging/bundles/manifest.toml` pins tool versions/URLs/licenses, `fetch-tools.sh` downloads + SHA-256-verifies against `bundles.lock`, stages the mpv/libmpv DLL dependency closure, and rejects a bundle missing ffmpeg.exe, ffprobe.exe, mpv.exe, gallery-dl.exe or libmpv-2.dll. A real fetch passed against every pinned hash and staged those five files plus d3dcompiler_43.dll; the generated disposable video and live libmpv frame smoke passed. Windows Host packages receive all helpers; Viewer packages receive libmpv and its DLL dependencies, and both receive third-party notices.
