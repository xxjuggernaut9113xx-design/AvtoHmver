# L-02 — Query/continuity

2026-11-06 browser and Server regression. Browser search now passes its text
to the shared library query before pagination, and continuation requests
retain that text. Previously the browser filtered only the initial batch
locally and could miss later matches or append unrelated results. The HTTP
test places direct and inherited tag matches after 150 unrelated items and
checks both pages, literal percent matching and source-domain matching. The
browser pagination test checks the request parameters and that concurrent
scrolls append the next page once.

Recorded: 2026-09-29. Migrated from the native workflow inventory; historical observations retain their original dates where stated.

search, sort, media-type, tag, rating, review, size, creator, source and group filters; previous/next; preserve query, scroll and selection. Native Library exposes the listed filters (including all/any/excluded tags and unknown size), keeps their controls across workspace switches, retains selection, and remembers scroll per cursor. After a page renders, a guarded next-turn restoration applies its remembered scroll position so the previous page geometry cannot clamp it; stale request IDs cannot restore an old position. New filter searches and source/group navigation clear stale cursors and scroll; older page results cannot replace the current query. The inspector uses retained selection even when the selected item is on another page; an automated test covers this case. Windows Host manual with 120 disposable items verified 100/20 pagination, previous/next, a retained off-page selection and inspector, filename search, source navigation with the search text retained, and grid/table switching.
